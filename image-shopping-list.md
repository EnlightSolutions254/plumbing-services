## Fastest path

If you want a shortcut: Unsplash's `/s/photos/` URL pattern lets you jump straight to results, e.g.:
`https://unsplash.com/s/photos/plumber-fixing-pipe`

Just swap the search term (spaces → hyphens) into that URL pattern for any row above.
